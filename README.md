# 40k Weekly Digest

Automated weekly content intelligence digest for Warhammer 40,000 creators and hobbyists.

Every Monday, this project researches the top trending content across Reddit, TikTok, Instagram, YouTube, Goonhammer, Warhammer Community, Dakka Dakka, Bolter & Chainsword, and Twitter/X — then ranks and publishes:

- **Top 5 Topics** — news, debates, memes gaining traction across the community
- **Top 5 Audios** — trending sounds and audio formats for short-form content
- **Top 5 Techniques** — hobby techniques AND content formats with high replication value

Items are ranked by composite score: engagement + velocity + cross-platform spread + community sentiment.
